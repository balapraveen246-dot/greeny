# 🌿 GreenDen -- Plant & Nature Website

GreenDen is a clean and responsive plant website designed to showcase
indoor plants and provide users with a simple and attractive browsing
experience.

The website includes a modern navigation bar, hero section, About Us
section, best-selling plants, product listing, product search area, and
a contact form.

> **Project Type:** Front-End Web Development\
> **Development Style:** Fully Hands-On Project\
> **Technologies:** HTML5 & Tailwind CSS

------------------------------------------------------------------------

## 🌱 Project Overview

GreenDen is created for people who love plants and nature. The website
provides a simple and attractive interface where users can explore
different plants, view popular products, search for products, and
contact the website.

The main goal of this project is to practice and demonstrate hands-on
front-end web development using **HTML5 and Tailwind CSS**.
